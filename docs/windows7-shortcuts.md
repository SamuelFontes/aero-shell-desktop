# Windows 7 desktop shortcuts

These defaults run inside AeroShell's private KWin session. They are installed for existing AeroShell profiles as well as first login. Plasma's shortcut configuration is not modified.

| Keys | Action |
|---|---|
| Windows, Ctrl+Esc | Start menu; type to search, arrows to select, Enter to launch |
| Win+E | Windows Explorer |
| Win+R | Run dialog; program names and arguments, folders, `explorer`, `taskmgr`, `cmd` |
| Win+F | Explorer folder search |
| Win+L | Lock through KScreenLocker |
| Ctrl+Alt+Delete | Security options: lock, log off, Task Manager |
| Ctrl+Shift+Esc | Task Manager |
| Win+D | Show/restore desktop |
| Win+M, Win+Shift+M | Minimize windows / restore the windows minimized by Win+M |
| Win+Home | Toggle minimizing other windows |
| Win+Left, Win+Right | Aero Snap |
| Win+Up | Maximize |
| Win+Down | Restore maximized window, then minimize |
| Alt+Tab, Alt+Shift+Tab | Switch windows forward/backward |
| Win+Tab, Win+Shift+Tab | KWin's alternative window switcher |
| Alt+Esc, Alt+Shift+Esc | Cycle windows in opening order |
| Alt+F4, Alt+Space | Close window / window operations menu |
| Win+1…9 | Open or activate taskbar application, including pinned Explorer/browser |
| Win+T, Win+B | Focus taskbar / notification area |
| Win+Pause | AeroShell settings |
| Print Screen, Alt+Print Screen | Copy desktop / active-window screenshot using Spectacle |

Explorer supports Alt+Left/Right, Alt+Up, Alt+D/Ctrl+L (address), Ctrl+E/F3 (search), Ctrl+N (new window), Ctrl+W (close), Ctrl+Shift+N (new folder), F2 (rename), F5 (refresh), Ctrl+A/C/X/V, Ctrl+Z/Ctrl+Y (undo/redo recorded copy/move/trash operations), Delete (Recycle Bin), Shift+Delete (confirmed permanent deletion), and Alt+Enter (properties). Search filters the current folder. Recycle Bin provides restore and confirmed emptying.

KWin's alternative switcher supplies Win+Tab; the legacy Windows Flip 3D effect is not implemented. Application-specific shortcuts remain the responsibility of those applications. Display projection, Magnifier, gadgets, and the complete Windows Control Panel are not yet implemented. This shortcut table describes the implemented defaults, not certification of complete Windows 7 parity.
