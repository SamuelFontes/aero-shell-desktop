| `CMAKE_INSTALL_FULL_BINDIR` launcher | Same session CMake rules | Replace upstream launcher with an AeroShell-owned launcher under a unique filename; avoid a hardcoded system-prefix path in private runtime files. |

| `DesktopNames=KDE` | Upstream Wayland desktop entry | Define and verify a separate AeroShell identity, including portal routing; document any compatibility identity actually required by a reused KDE component. |
| `${CMAKE_INSTALL_PREFIX}/share/{smod,kwin,aeroshell}` | AeroShell KWin CMake | Configure a private prefix and confirm these plugin/script directories are not searched by regular KDE. |
| `install(DIRECTORY .../smod|kwin|outline)` | AeroShell KWin Components root CMake | The audited `Plasma/6.7` root file sets `KWIN_BUILD_WAYLAND` to `OFF` by default; Wayland dependencies are declared when enabled. | MIME database update at `/usr/local/share/mime` | Upstream `install.sh` | Remove the global update action; provide only any application MIME data needed through a private/user-local mechanism shown to avoid KDE side effects. |

## Development host version observation

Read-only package queries on the current Manjaro development environment reported KWin 6.7.4, Plasma Workspace and Plasma Desktop 6.7.4, Qt 6.11.2, Qt Wayland 6.11.2, Wayland protocols 1.49, and Extra CMake Modules 6.29.0. The upstream AeroThemePlasma README reports testing with Plasma 6.7.4, Frameworks 6.28.0, and Qt 6.11.1. These observations do not establish ABI compatibility and this live development environment is not an end-to-end install target. Do not install or alter the current desktop to test AeroShell.

A `startplasma-wayland --version` probe did not exit as a version query, so it was interrupted. A subsequent process check found no `startplasma-wayland`, `plasmashell`, or `kwin_wayland` process in the command environment. Do not use session launchers as version-query commands.

## In-repository core staged manifest

The latest CMake stage audits 8,474 entries: the shell and session files, KWin compatibility checker, mandatory Windows 7 Aero icon theme and sound theme, Aero cursor, AeroThemePlasma wallpaper and color scheme, Start orb, GTK style, fontconfig and Qt Quick Controls defaults, Aurorae decoration, AeroThemePlasma-derived lock-screen package and lock defaults, and licenses. `scripts/audit-install-manifests.py` accepts the tree under `/opt/aeroshell` and the exact Wayland session, launcher, and AeroShell-specific portal selector paths, and rejects SDDM-named destinations anywhere. The host target-collision audit passes for this manifest. This does not demonstrate live Wayland protocol behavior, secure lock/unlock, Qt/KDE application styling, or package lifecycle; the desktop is not release-ready.
